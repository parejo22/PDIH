## Ejercio: Repetir el mensaje 7 veces:
Para hacer este ejercicio solo tengo que cambiar 3 lineas con respecto al codigo anterior 
```asm
mov cx,7
....
bucle:
.....
loop bucle
```
Primero establezco el contador en 7
Creo una etiqueta llamada bucle que marca el inicio del bucle
Y por último cada vez que pase por loop bucle el contador, decrementara en 1 hasta que llegue a 0.
```asm
pila segment stack 'stack'
	dw 100h dup (?)
pila ends
datos segment 'data'
	msg db 'Thats how we roll',13,10,'$'
datos ends
codigo segment 'code'
	assume cs:codigo, ds:datos, ss:pila
	main PROC
		mov ax,datos
		mov ds,ax

		mov ah,08h
		int 21h
		mov cx,7
		
		bucle:
		mov dx,OFFSET msg
		mov ah,9
		int 21h

		loop bucle

		mov ax,4C00h
		int 21h
	main ENDP
codigo ends

END main
```
